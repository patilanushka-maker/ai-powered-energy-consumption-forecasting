# 03. Modules & Components

## Overview
*Breakdown of the codebase modules, responsibilities, public interfaces, and component interactions.*

---

## Planned Module Structure
- `src/data/`: Data loading, cleaning, validation, and splitting.
- `src/features/`: Feature engineering, time encodings, lag calculators, and scalers.
- `src/models/`: Model definitions, architectures, loss functions, and inference interfaces.
- `src/training/`: Training loops, hyperparameter optimization, early stopping, and checkpointing.
- `src/evaluation/`: Metric computation (MAE, RMSE, MAPE, R²), residual analysis, and visualization.
- `src/utils/`: Configuration management, logging, and seed reproducibility.
