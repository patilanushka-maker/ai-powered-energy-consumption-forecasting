# Outputs Directory

This directory stores outputs generated by evaluation pipelines, model analysis, and experimental runs.

---

## Subdirectory Breakdown

```
outputs/
├── figures/        # Generated visual plots, diagnostic graphs, and residual charts
│   └── .gitkeep
├── metrics/        # Tabulated metrics, evaluation summaries (CSV / JSON), and benchmark tables
│   └── .gitkeep
└── README.md       # Outputs documentation
```

---

## Expected Outputs

1. **`figures/`**:
   - Forecast vs. Actual comparison plots
   - Residual error distribution plots
   - Feature importance bar charts
   - Time-series decomposition (trend, seasonality, noise) plots

2. **`metrics/`**:
   - Test evaluation summaries recording MAE, RMSE, MAPE, and $R^2$ scores across models
   - Cross-validation fold performance tables
   - Inference latency benchmarks
