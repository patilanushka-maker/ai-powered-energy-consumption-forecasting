# Visual Assets Directory

This directory stores visual assets and documentation screenshots for the project.

---

## Directory Contents

- phase4a_actual_vs_predicted.png: Empirical test set evaluation plot from Phase 4A comparing actual energy consumption against Random Forest predictions and persistence baselines.
- dashboard_overview.png: Screenshot placeholder for the Streamlit dashboard overview section.
- forecast_rollout.png: Screenshot placeholder for the interactive multi-step recursive forecasting section.
- model_evaluation.png: Screenshot placeholder for the model benchmark scorecard section.

Users can capture screenshots of their local Streamlit instance (running at http://localhost:8501) and save them to this directory to display them in the root README.md file.
